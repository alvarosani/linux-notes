
`NAVEGACION`
pwd - directorio actual
ls - listar archivos del directorio actual | [[options.ls]]
cd - cambiar de directorio | [[options.cd]]
whoami -  ver el usuario actual

`ARCHIVOS Y DIRECTORIOS`
mkdir - crear nuevo directorio | [[options.mkdir]]
touch - crear un archivo | [[options.touch]]
cp - copiar archivo o directorio | [[options.cp]]
mv - mover archivo o directorio | [[options.mv]]
rm - borrar archivo | [[options.rm]]
rmdir - borrar directorio | [[options.rmdir]]

`VER CONTENIDOS`
cat - muestra el contenido de un archivo | [[options.cat]]
less - igual que cat pero en modo paginado
head - muestra las primeras líneas de un documento
tail - muestras las ultimas líneas de un documento
nano - editar archivo de texto | [[options.nano]]
